How it works

1. Paste a public Kick clip link and tap Get Clip — the page reads the clip's public details from Kick.
2. Watch the preview, then tap Download MP4 — the clip is fetched and re-wrapped into a standard MP4 file right in your browser (no re-encode, original quality kept).
3. Save the file. It plays in any video player — gallery, VLC, MX Player.

Honest limits: only public clips work. Some very long clips can be large (tens of MB) and take a while on slow connections — the progress bar shows the real download. If the MP4 step ever fails, the page offers the raw stream file (.ts) as a fallback.
