How it works & honest limits

Data comes live from the Internet Archive's free Availability API — no key, no signup, nothing uploaded. The full snapshot list (CDX API) cannot be read directly from a browser page, so the timeline shows one snapshot per year instead of every single capture. A snapshot shows the page as it was on that date, including its old design — and a snapshot can itself be a redirect or an error page if that is what the archive captured. Saving a page uses archive.org's own Save Page Now service.
