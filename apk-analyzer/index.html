How it works

  1. Pick an APK — from your downloads, a backup, or your own build.
  2. It is unzipped in your browser (JSZip) and the binary AndroidManifest.xml is decoded by a built-in parser — package, version, SDK levels, permissions, activities, services, receivers, providers, native libraries and signing info.
  3. Read the report — dangerous permissions are explained in plain English and risky flags (debuggable, cleartext traffic, old target SDK) are highlighted.

This tool reads the manifest and file list only. It does not decompile code — for code, use JADX or apktool on a computer. A clean report here does not mean an app is safe; it only shows what the app declares it can do.
