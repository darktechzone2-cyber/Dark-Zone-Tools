DTZ Subdomain Finder

Enter any domain and find every subdomain that has ever appeared in public SSL certificate logs — including forgotten staging, dev and admin hosts. Each result is checked live in DNS, and you can export the full list. Free, no sign-up, public data only.

How it works: Every public SSL/TLS certificate is recorded in Certificate Transparency logs. This tool reads those public logs (crt.sh, with SSLMate Cert Spotter as fallback), extracts every hostname, then checks each one live using Cloudflare DNS-over-HTTPS. Limits: hosts that never had a public certificate, or that hide behind a wildcard certificate (*.domain), cannot appear in the logs. crt.sh is a free community service and can be slow at busy times — if a search fails, wait a few seconds and try again. Use this tool only on domains you own or have permission to test.
