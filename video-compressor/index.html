    How it works & limits

    • Compression uses real H.264 (libx264) encoding inside your browser via ffmpeg.wasm — nothing is uploaded to any server.
    • The engine (~25 MB) downloads once from jsDelivr on first use. If it cannot load, check your connection and reload.
    • Works best in Chrome or Edge on desktop and Android. On iPhone, use Safari and keep the tab in the foreground while it runs.
    • Very large or very long videos use a lot of memory — the file cap is 100 MB. A 1-minute 720p clip usually takes under a minute.
    • Output is always MP4 (H.264 + AAC) with faststart, so it plays instantly on WhatsApp, Telegram and any phone.
